# Pizarro Studios

Public proof portfolio for Pizarro Studios. It is a static site with no build step.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` in a browser.

## Publish before outreach

1. Deploy `index.html` to a public host such as GitHub Pages, Netlify, or Vercel.
2. Open the published link in a private/incognito browser window to verify it requires no login.
3. Confirm the email and phone links work on mobile.
4. Use the public URL—not a private Drive or development preview link—in outreach.

The page intentionally distinguishes prototypes, MVPs, and demonstrated work from customer outcomes. Keep that discipline when adding projects or case studies.

## Cinematic production system

`cinematic/` holds the visual and video system for Pizarro Studios — the rulebook, the shot-by-shot
plan for the first brand film, paste-ready generation prompts, sound direction, and the code for
putting video on this site. Start at `cinematic/README.md`.
